# My Portfolio

This very website! It's built with:
- **Next.js 16** (App Router, static export)
- **Tailwind CSS**
- **MDX** for content
- **Custom Theme System**

It features a custom "window light" aesthetic in light mode and a "door crack" bleed in dark mode.
